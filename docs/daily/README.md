# ŞifreKasa — Günlük (Daily) Kayıt Sistemi

Her çalışma gününde yapılan incelemeler, geliştirmeler, alınan kararlar, test sonuçları, engelleyiciler ve sonraki günün hedefleri bu dizinde `YYYY-MM-DD.md` adıyla tutulur.

## Kurallar

1. Her yeni çalışma gününde `TEMPLATE.md` kopyalanarak `YYYY-MM-DD.md` oluşturulur.
2. Aynı gün içinde birden fazla oturum yapılırsa ilgili günün dosyası güncellenir.
3. Tamamlanan işler ilgili Backlog ID'siyle (`INFRA-01`, `GP-02`, `TEST-01` vb.) bağlanır.
4. Test sonuçları somut komut çıktısı özetleriyle yazılır.
5. Yeni mimari karar veya teknik tuzak varsa aynı zamanda `docs/project/MEMORY.md` dosyasına işlenir.
